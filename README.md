
# 🎮 Connect 4 Game

A simple and fun **Connect 4 Game** built using **HTML, CSS, and JavaScript**.  
This is a two-player browser game where players take turns to connect 4 discs in a row to win.

---

## ✨ Features

✔️ Two Player Gameplay  
✔️ Win Detection System  
✔️ Reset Game Functionality  
✔️ Clean and Interactive UI  
✔️ Responsive Grid Layout  

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

---

## 🚀 How to Run

1. Download or clone this repository
2. Open the project folder
3. Run `index.html` in your browser

---

## 🎯 Game Rules

- Players play turn by turn
- Connect **4 discs** in:
  - Horizontal direction
  - Vertical direction
  - Diagonal direction
- First player to connect 4 discs wins the game
